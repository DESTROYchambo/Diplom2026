# Розробка 2D гри у жанрі симулятор «GardenTale»

Кваліфікаційна робота на підтвердження ступеня фахового молодшого бакалавра ([ВСП «ППФК НТУ «ХПІ» (http://polytechnic.poltava.ua)). Керівник роботи – **Олійник Владислав Васильович**.

## Завдання до дипломної роботи
Розроблений програмний продукт має являти собою 2D-гру у жанрі симулятор розроблений за допомогою рушія GoDot. Основна мета гравця – розвивати своє господарство(ферму). Розробку виконати за допомогою мов С# та GDScript. Слід подбати про зручне меню та наявність мапи, реалізувати взаємодію з іншими персонажами та навколишнім світом(дерева, кущі, тощо), реалізувати інвентар(склад), тощо. Готовий продукт опублікувати в одному з онлайнових ігрових магазинів (itch.io тощо).

## Використані технології
* Godot Engine 4.5
* GDScript
